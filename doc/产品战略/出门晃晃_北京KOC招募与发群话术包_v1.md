## 2. KOC 是什么、招什么样的人

**KOC（Key Opinion Consumer）** 在这里指：愿意**每周在北京组 1–2 场小型线下局**，并愿意在自己私域（微信群/朋友圈）里分享报名链接的人。

### 2.1 优先招募画像

| 类型 | 举例 | 为什么合适 |
|------|------|------------|
| 社群活跃分子 | 徒步群、跑团、桌游群常组局的人 | 已有组局习惯 |
| 咖啡 / 探店爱好者 | 周末爱找饭搭子 | 场景匹配 |
| 旅居 / 数字游民 | 北京短住、常换人社交 | 产品核心用户 |
| 独居上班族 | 下班想出门但缺人 | 同城画像 |
| 小红书 / 豆瓣同城发帖者 | 有内容、有私域 | 自带传播 |

### 2.2 不优先招

- 以婚恋/dating 为目的的组局者
- 导流卖课、卖保险、婚恋中介
- 无法保证每周至少 1 局、且不愿在群内分享者

### 2.3 招募目标（第 1 个月）

| 阶段 | 人数 | 标准 |
|------|------|------|
| 种子 KOC | **10 人** | 每人承诺 2 周内发 2 局 |
| 稳定 KOC | **30 人** | 每人每周 ≥1 局，月有效邀请 ≥1 |

## 3. 招募话术（私聊用）

### 3.1 冷启动私聊（朋友 / 社群认识的人）

```
嗨，我们在做一个小程序「出门晃晃」——帮北京想出门的人组小型线下局（咖啡、citywalk、夜跑那种），6–8 人，公共场所见面。

想邀请你当第一批「认证组织者」：
· 你定时间地点主题，在小程序发活动
· 报名、群聊、人数我们产品在管
· 你发到自己的微信群就行，拉来人报名还有曝光奖励（活动可置顶）

这周能试着组一场吗？咖啡局 2 小时就行，我们官方帮你补几个人凑局。
```

### 3.2 社群招募（徒步/桌游/旅居群）

```
【组织者招募·北京】

小程序「出门晃晃」找北京愿意组小局的朋友。
适合：周末想组咖啡局/citywalk/夜跑，缺个报名和群聊工具的人。

· 认证后免费发活动
· 6–8 人小局，公共场所
· 不是 dating，是「一起做点事」

有兴趣私聊，第一周我们帮推流凑人。
```

### 3.3 招募后 onboarding（3 步）

1. 完成小程序登录 + 组织者认证（按产品流程）
2. 运营帮发第一场「模板局」（见 §5）
3. 加「出门晃晃·北京组织者」小群（10–30 人），每周同步局单

---

## 4. KOC 要做什么（每周 checklist）

- [ ] 本周在小程序发布 **≥1 场**活动（建议固定模板：咖啡 / citywalk）
- [ ] 发到自己 **≥1 个微信群**（可同步朋友圈）
- [ ] 局前在群里确认人数、时间、地点
- [ ] 局后（可选）：现场让新用户扫码，或分享下一场局
- [ ] （可选）邀请 1 位朋友注册并完成加群/报名 → 拿邀请奖励

## 5. 四类模板局（北京首发推荐）

| 模板 | 时长 | 人数 | 地点建议 | 标题示例 |
|------|------|------|----------|----------|
| 下班咖啡局 | 2h | 6 | 望京/国贸/中关村连锁咖啡 | 「周五下班·望京咖啡闲聊」 |
| 周末 citywalk | 3–4h | 8 | 奥森/什刹海/798 等 | 「周日午后·奥森散步拍照」 |
| 夜跑社交局 | 1.5h | 6 | 奥森/滨河公园 | 「周二夜跑·5km 慢跑聊天」 |
| 桌游破冰局 | 2–3h | 6 | 桌游吧或咖啡厅包间 | 「周六桌游·新手友好」 |

**费用说明建议写：** `AA 制，预计人均 30–50 元` 或 `免费，咖啡自理`

## 6. 发群话术包（复制即用）

> 使用时替换【】内内容；活动链接用小程序「分享」或「活动分享码」。

### 6.1 还差人（报名前 24–48h）

```
【周六下午】我在「出门晃晃」组了个小局：

📍 【望京某某咖啡】
⏰ 【14:00–16:00】
👥 【6 人局，还差 2 人】
主题：【下班闲聊 / citywalk / 夜跑】，公共场所见面～

感兴趣的微信里点开小程序报名就行，报名后进活动群对齐。
新人友好，独行/独居来北京的也欢迎。
```

### 6.2 刚发局（满员压力不大时）

```
这周末想出门走走，在「出门晃晃」发了一场【咖啡局/citywalk】，北京【朝阳】附近，6 人小局。

小程序搜「出门晃晃」或点我分享的卡片就能报名。
不是相亲局，就是一起做点事、聊聊天～
```

### 6.3 局后复盘 + 下一场预告

```
昨天【咖啡局】顺利成局，感谢来的朋友～

下一场【周日 citywalk·奥森】已发，还在出门晃晃，欢迎一起。
```

### 6.4 邀请好友进北京圈子（偏邀请码，非具体局）

```
最近在用「出门晃晃」找北京周末局——咖啡、徒步、 citywalk 都有，公共场所见面比较安心。

独行/独居/换城市的朋友挺合适。我邀请码：【XXXXXX】
注册后 7 天内加入北京大群或随便报个局就行。
```

### 6.5 朋友圈（短版）


## 7. 分享操作指引（给 KOC）

### 7.1 分享「这一场局」（优先）

1. 打开**活动详情页**
2. 点右上角 **分享给好友** → 发到微信群
3. 或点 **活动分享码** → 保存图片发群公告

好友打开后会在首页**置顶看到这场活动**。

### 7.2 分享「邀请进北京圈子」

1. 打开 **我的 → 信任中心 → 邀请好友**（或「邀请好友」页）
2. 点 **分享给好友** 或 **复制邀请码**
3. 说明：好友 **7 天内加群或报名** 才算邀请成功

分享路径含邀请码：`/pages/entry/entry?inv=你的码`

## 8. KOC 激励（与产品一致，可口头解释）

| 做到 | 得到 |
|------|------|
| 好友注册且 7 天内加群/报名 | 累计有效邀请 +1，阶梯奖励（权益/徽章） |
| 有效邀请 5 人 | 活动 **置顶 1 次**（24h） |
| 每周稳定发局 | 运营优先推荐、城群曝光（人工协调） |
| 完成照片验证 | 邀请奖励时长 **+20%** |

**不做现金返利**，避免刷单和合规问题。

## 10. 常见问题（KOC FAQ）

**Q：和微信群直接组局有什么区别？**  
A：小程序有报名人数、活动群、认证与举报，陌生人更敢来；你仍可在自己的群里喊人。

**Q：有人报名不来怎么办？**  
A：小局可多报 1–2 人缓冲；活动前在群里确认；恶意放鸽子可联系运营处理。

**Q：安全吗？**  
A：建议公共场所、首次不见面转账；平台有举报/拉黑；详情页有安全提示。

**Q：邀请码怎么用？**  
A：朋友点你的分享卡片注册，或登录后输入邀请码；7 天内加北京大群或报局即算成功。

**Q：能赚钱吗？**  
A：现阶段无现金返利；有效邀请换曝光置顶和权益。收费局未来可走平台报名（待定）。
