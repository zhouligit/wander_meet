> **产品阶段**：全国城市开放，微信小程序（含**城市大群** + 线下活动双主线）。

## 一、一句话介绍（开场 10 秒）

**旅聚**是一款微信小程序——无论你人在**哪座城市**，都能快速找到同路人：

- 先加入这座城的 **「城市大群」**，和同城旅人持续交流、拼饭、找搭子；  
- 再报名具体的 **线下小活动**，咖啡、 citywalk、桌游、夜跑……**今天就能成局见面**。

**核心承诺：今天就能找到人，一起做点事。**

---

## 二、我们在解决什么问题？

很多人都有这种时刻：

- **刚到一座陌生城市**（出差、旅居、旅行），想先有个「本地人 / 同路人」信息入口，而不是从零开始加一堆群  
- **长期独居在某城**，周末想出门社交，但朋友圈凑不齐人  
- **活动意向有，但缺前置连接**——不知道谁先聊、谁靠谱，直接报局心里没底  

传统社交产品往往是：**先匹配、再聊天、再约**——链条长、意图模糊。

**旅聚用两条线把路缩短：**

| 主线 | 解决什么 |
|------|----------|
| **城市大群（重要）** | 「我在这座城市」→ 先进**同城大群** → 持续弱连接、随时发问、拼饭找搭子，再自然转到具体活动 |
| **线下活动** | 「我想今天/明天出门」→ 直接浏览、报名**有主题的小局** → 群聊对齐 → 线下见面 |

## 三、产品定位（帮主播理解「该对谁讲」）

| 维度 | 说明 |
|------|------|
| **是什么** | 全国城市的**同城社交**小程序：**城市大群** + **线下活动组局** 双核心 |
| **不是什么** | 不是 dating App，不是无限滑卡的交友软件，也不是只有活动、没有社群的空壳列表 |
| **给谁用** | 独行旅行者、数字游民、**同城独居青年**、出差换城的人、周末想扩大圈子的上班族 |

## 四、用户怎么用？（45 秒讲清「双主线」）

### 4.1 城市大群（建议主播优先讲）

适合口播的 **四步**：

1. **发现页进入「城市大群」** → 按**省份展开**，点选自己所在的**市 / 区县**  
2. **加入该城大群** → 确认后加入；与同地址旅人进入**同城群聊**  
3. **在群里交流** → 问路、拼饭、找搭子、可发**定位**约汇合点；消息列表里会显示「城市大群」会话  
4. **再报名活动** → 从群里或首页、发现页进入具体线下局，把弱连接变成真实见面  

> **主播金句**：「换城市不用从零社交——**先进这座城的大群**，再决定周末去哪个局。」

### 4.2 线下活动（第二条线）

1. **打开小程序** → 微信登录，完善资料  
2. **逛活动** → 首页看「今天 / 明天」能参加的局；可按距离、分类筛选；**搜地点**（商圈 / POI）看附近活动  
3. **报名加入** → 进入**活动群聊**，对齐时间地点  
4. **线下见面** → 到场；可反馈、举报  

**想自己组局？** 认证后**发布活动**（时间、地点、人数、说明），等人报名。

## 五、核心功能亮点（口播可挑 4～6 条）

### 5.1 城市大群 —— 全国同城入口（⭐ 重点推荐）

这是旅聚区别于「只有活动列表」的**核心能力**，推广时建议**至少用 15～20 秒专门讲**。

| 要点 | 说明 |
|------|------|
| **全国目录** | 发现页 →「城市大群」→ **按省展开**，选市 / 区县，覆盖全国城市节点 |
| **一城一群** | 每个城市节点对应一座城的**官方大群**（同城旅人公共会话） |
| **先进群、后组局** | 不强制先报活动；在群里可先聊、先认识，再报名咖啡局、 citywalk 等 |
| **持续连接** | 大群在消息页长期存在，适合「刚到成都第一周」「常驻上海」等**中长期**场景 |
| **与活动打通** | 大群与活动群聊体验一致（微信式气泡）；我的活动列表区分「城市大群」与「普通活动」 |

**适合主播的讲法：**

- 「旅聚不只是周末找局，更是**每座城市都有一个旅人大本营**。」  
- 「你飞到厦门、驻留杭州、北漂北京——**先加对应城市大群**，比在小红书评论区碰运气靠谱。」  
- 「活动是『强见面』，大群是『弱连接』——**两条线一起用，社交才不断档**。」

### 5.2 线下活动 —— 高意图成局

- 每个局有**明确主题、时间、地点、人数**  
- 发现页分类：咖啡、 citywalk、徒步、桌游、展览、夜跑等  
- 列表可见名额、距离、开始时间——**活动本身就是话题**，降低尬聊成本  

### 5.3 搜地点找活动

- 先选城市或区域，再按**地点锚点**看附近能报的活动  
- 适合「我在三里屯 / 春熙路 / 西湖边，今天有什么局？」类口播  

### 5.4 活动群聊 + 私聊（有边界）

- **活动群聊 / 城市大群聊**：成员可见，行前或同城协调  
- **私聊**：需在同一活动语境下、经申请同意，减少骚扰  
- 界面风格贴近微信聊天习惯，上手快  

### 5.5 安全与信任（必讲）

- **发布活动需认证**  
- 聊天页、个人页可**举报、拉黑**  
- 安全提示：公共场所见面、勿私下转账  
- 运营审核与封禁（骚扰、诈骗等）  

### 5.6 微信即用

- 无需单独下载 App，直播间 / 评论区可直接引导「微信打开小程序」

## 十、常见问题 FAQ（直播弹幕可用）

**Q：这是 dating 软件吗？**  
A：不是。旅聚是**城市大群 + 线下活动**，核心是同城交流与一起参加活动，不是左滑匹配。

**Q：我不在北京能用吗？**  
A：可以。**全国城市**都能在目录里选城，加入对应的**城市大群**；线下活动看各城当前供给。

**Q：城市大群和活动群有什么区别？**  
A：**城市大群**是按城市划分的长期同城交流场，适合刚到一城、常驻、问路拼饭；**活动群**是报名某个具体局之后的临时群，用于对齐那场活动的时间地点。

**Q：大群要花钱吗？**  
A：加入城市大群本身不另收「入群费」（以产品内展示为准）；具体线下活动是否 AA / 免费看活动详情。

**Q：怎么保证安全？**  
A：发活动需认证；可举报拉黑；建议公共场所见面、勿私下转账；运营处理违规账号。

**Q：我可以自己组局吗？**  
A：可以。认证后在小程序发布活动；也可先在**城市大群**里找同城成员。

**Q：和 NomadTable 什么关系？**  
A：旅聚是**独立中国产品**（微信小程序、全国城群），体验上同属旅人 / 同城组局赛道，无隶属关系。
