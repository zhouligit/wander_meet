## 重新生成材料

```bash
cd wander_meet
python3 -m venv .venv-soft-reg && .venv-soft-reg/bin/pip install -r requirements-soft-reg-pdf.txt
.venv-soft-reg/bin/playwright install chromium   # 首次
.venv-soft-reg/bin/python scripts/rebuild_soft_registration.py
```

或分步：

```bash
.venv-soft-reg/bin/python scripts/soft_registration_export.py
.venv-soft-reg/bin/python scripts/sanitize_soft_registration_outputs.py
.venv-soft-reg/bin/python scripts/build_soft_registration_pdf.py
.venv-soft-reg/bin/python scripts/capture_h5_screenshots.py      # 原始截图
.venv-soft-reg/bin/python scripts/build_doc_identification_pdf.py
```

真机截屏替代 H5：将 PNG 按 `scripts/build_doc_identification_pdf.py` 中 `CAPTION_TO_FILE` 覆盖 `doc/soft_registration/screenshots/` 后，仅重跑 `build_doc_identification_pdf.py`。
